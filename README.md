# Claude Garden

A growing collection of Claude Code skills, agents and hooks.

## Installation

### Add Marketplace

```bash
/plugin marketplace add wenjiecome/claude-garden
```

### Install Plugin

```bash
/plugin install garden@claude-garden
```
